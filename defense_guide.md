# Гайд по защите курсовой работы
## «Магазин компьютерных игр»

---

## 1. Запуск программы (сделать заранее, за 5 минут)

1. Открыть **Терминал**
2. Ввести команды:

```bash
cd ~/Desktop/java
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
mvn spring-boot:run
```

3. Дождаться строки `Started Application` в консоли
4. В браузере открыть: **http://localhost:8080**

---

## 2. Порядок демонстрации (5–7 минут)

### Шаг 1 — Вкладка «Игры»
- Показать таблицу с играми
- Нажать **«Добавить»** → заполнить поля → **«Сохранить»** — новая строка появилась
- Выбрать строку → **«Изменить»** → изменить цену → **«Сохранить»**
- Выбрать строку → **«Удалить»** → подтвердить

> *«Здесь хранится каталог игр. У каждой игры есть название, цена, жанр и разработчик.»*

### Шаг 2 — Вкладки «Жанры» и «Разработчики»
- Быстро показать данные, добавить одну запись

> *«Это справочники — жанры и разработчики, к которым привязаны игры через внешние ключи.»*

### Шаг 3 — Вкладка «Покупатели»
- Показать список, добавить нового покупателя

> *«Учёт клиентов магазина с контактными данными и датой регистрации.»*

### Шаг 4 — Вкладка «Покупки»
- Показать таблицу: дата, сумма, статус, количество

> *«Покупки связывают покупателя с игрой — видно когда куплено и на какую сумму.»*

### Шаг 5 — Вкладка «Дашборд» ⭐ главное
- Показать 4 карточки: доход, покупки, покупатели, игры
- Показать **график продаж по месяцам**
- Показать **круговую диаграмму по жанрам**
- Удалить запись в другой вкладке → вернуться на Дашборд → данные обновились

> *«Дашборд обновляется в реальном времени и показывает ключевые метрики магазина.»*

### Шаг 6 — Показать код (если попросят)
- `MainView.java` — структура вкладок и кнопок
- `GameService.java` — SQL-запросы через JDBC
- `DashboardView.java` — расчёт статистики и SVG круговая диаграмма

## 3. Топ-10 вопросов и ответы

### В1. Что делает ваша программа?
Веб-приложение для управления магазином компьютерных игр. Позволяет вести каталог игр, учитывать покупателей и покупки, управлять жанрами и разработчиками, анализировать продажи через дашборд.

---

### В2. Какие технологии использованы?
- **Spring Boot** — основа приложения и встроенный сервер
- **Vaadin** — веб-интерфейс на Java без HTML/JS
- **H2** — встроенная реляционная база данных
- **Maven** — сборка проекта

---

### В3. Почему H2, а не MySQL или PostgreSQL?
H2 запускается прямо внутри приложения — не нужен отдельный сервер. Поддерживает полный SQL-стандарт. При необходимости легко переключить на PostgreSQL, изменив только строку подключения в `application.properties`.

---

### В4. Как связаны таблицы в базе данных?
Через внешние ключи:
- `Game` → `Genre` и `Developer`
- `Purchase` → `Game` и `Customer`

При удалении игры автоматически удаляются её покупки (`ON DELETE CASCADE`).

---

### В5. Что такое Spring Boot и зачем он нужен?
Фреймворк для быстрой разработки Java-приложений. Берёт на себя конфигурацию, встроенный веб-сервер Tomcat и управление зависимостями через DI-контейнер (Spring IoC).

---

### В6. Что такое Vaadin и почему выбран он?
Java-фреймворк для создания веб-интерфейса полностью на Java — без HTML и JavaScript. Компоненты: Grid, Button, Dialog, ComboBox, DatePicker. Выбран для упрощения разработки UI в рамках Java-проекта.

---

### В7. Как реализован CRUD?
Для каждой сущности есть `*Service` класс с методами `getXxx`, `createXxx`, `updateXxx`, `deleteXxx` через JDBC `PreparedStatement`. `DialogManager`-классы открывают диалоги и вызывают методы сервиса при нажатии кнопок.

---

### В8. Какова архитектура приложения?
Трёхуровневая:
```
View (Vaadin — интерфейс)
  ↓
Service (бизнес-логика, SQL-запросы)
  ↓
Database (H2)
```
Модели — POJO-классы: `Customer`, `Game`, `Purchase`, `Developer`, `Genre`.

---

### В9. Как работает дашборд?
При переключении на вкладку «Дашборд» данные заново загружаются из базы. Считается общая выручка, продажи по месяцам и распределение по жанрам. Круговая диаграмма построена через SVG без сторонних библиотек.

---

### В10. Что будет при удалении жанра или разработчика?
Благодаря `ON DELETE CASCADE` сначала удаляются все игры этого жанра/разработчика, затем удаляются все покупки, связанные с этими играми. Это обеспечивает ссылочную целостность базы данных.
